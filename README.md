# SQL-Data-Analysis-Using-Northwind-Database

## Project Overview

This project demonstrates SQL-based data analysis using the Northwind Database in PostgreSQL. The objective is to extract meaningful business insights from structured data by applying SQL concepts such as filtering, sorting, aggregations, joins, subqueries, views, and indexing.

The project analyzes sales performance, customer purchasing behavior, product demand, and revenue generation using real-world business scenarios.

---

## Objective

* Retrieve and analyze sales data using SQL queries.
* Perform customer and product analysis.
* Calculate revenue and average order values.
* Use joins to combine data from multiple tables.
* Apply aggregate functions for business reporting.
* Create views for reusable analysis.
* Optimize query performance using indexes.

---

## Dataset

**Northwind Database**

The Northwind database is a sample business database containing information about:

* Customers
* Orders
* Order Details
* Products
* Categories
* Suppliers
* Employees
* Shippers
